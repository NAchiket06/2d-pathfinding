How it maps to Unity

Each link is directional with a weight. Traversal cost is distance * weight, where distance is the curve length for spline links. The heuristic is straight-line distance scaled by min(1, cheapest weight), so it never overestimates. Turning on "Disable heuristic" makes it Dijkstra, which expands more nodes.
